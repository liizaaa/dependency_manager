Что такое composer.json?

composer.json — основной файл конфигурации проекта, который использует менеджер зависимостей Composer.

В этом файле указываются зависимости PHP-проекта, информация о самом проекте, версии пакетов и дополнительные настройки.

Файл обычно располагается в корневой директории проекта.

Пример composer.json 
{
    "name": "example/project",
    "description": "Учебный PHP-проект",
    "require": {
        "monolog/monolog": "^3.0"
    }
}

В данном примере проект использует библиотеку Monolog.

Основные поля composer.json
  • name — название проекта.
  • description — описание проекта.
  • require — основные зависимости проекта.
  • require-dev — зависимости, необходимые для разработки и тестирования.
  • autoload — настройки автоматической загрузки классов.
  • scripts — команды, которые можно запускать через Composer.
require и require-dev

require

В разделе require указываются пакеты, необходимые приложению для нормальной работы. 

{
    "require": {
        "monolog/monolog": "^3.0"
    }
}

require-dev

В разделе require-dev указываются пакеты, которые используются во время разработки, тестирования или отладки. 

{
    "require-dev": {
        "phpunit/phpunit": "^11.0"
    }
}
Как создать composer.json?

Создать новый файл конфигурации можно с помощью команды: 

composer init

Composer запустит пошаговый процесс настройки проекта и поможет создать файл composer.json.

Каталог vendor

После установки зависимостей Composer создаёт каталог vendor.

В нём находятся установленные PHP-пакеты и служебные файлы, необходимые Composer для автоматической загрузки зависимостей.

Аналогичную роль в проектах NPM выполняет каталог node_modules.
