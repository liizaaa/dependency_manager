Что такое Composer?

Composer

Composer — это система управления зависимостями для языка программирования PHP.

С помощью Composer разработчик может подключать сторонние библиотеки, управлять их версиями и автоматически устанавливать необходимые зависимости проекта.

Основная информация о зависимостях хранится в файле composer.json.

Основные возможности Composer
  • Установка PHP-библиотек
  • Управление версиями зависимостей
  • Обновление пакетов
  • Удаление зависимостей
  • Автоматическая загрузка библиотек
  • Работа с Packagist
Основные команды

Создание файла composer.json: 

composer init

Установка всех зависимостей проекта: 

composer install

Добавление новой зависимости: 

composer require monolog/monolog

Обновление зависимостей: 

composer update

Удаление зависимости: 

composer remove monolog/monolog
Файл composer.json

Файл composer.json содержит информацию о проекте и его зависимостях.

Например, зависимость от библиотеки Monolog можно указать следующим образом: 

{
    "require": {
        "monolog/monolog": "^3.0"
    }
}

После добавления зависимости Composer устанавливает необходимые файлы в каталог vendor.

Где используется Composer?

Composer широко применяется в PHP-проектах. Он используется как в небольших учебных проектах, так и в крупных веб-приложениях.

  1. Создание PHP-проекта
  2. Добавление необходимых библиотек
  3. Установка зависимостей
  4. Разработка приложения
  5. Обновление зависимостей при необходимости
