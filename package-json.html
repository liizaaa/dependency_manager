Что такое package.json?

package.json — это основной файл проекта, использующего NPM. В нём хранится информация о проекте, его зависимостях, скриптах и других настройках.

Благодаря этому файлу разработчик может описать, какие пакеты необходимы проекту и какие команды используются для его запуска или сборки.

Файл находится в корневой папке проекта.

Пример package.json
{
  "name": "dependency-manager",
  "version": "1.0.0",
  "description": "Учебный проект о системах управления зависимостями",
  "main": "index.js",
  "scripts": {
    "start": "node index.js"
  },
  "dependencies": {
    "98.css": "^0.1.20"
  }
}

В данном примере проект использует библиотеку 98.css как зависимость.

Основные поля
  • name — название проекта.
  • version — версия проекта.
  • description — краткое описание.
  • main — основной файл приложения.
  • scripts — команды, которые можно запускать через NPM.
  • dependencies — зависимости, необходимые для работы проекта.
dependencies и devDependencies

Зависимости проекта обычно разделяются на две основные категории.

dependencies

Это пакеты, которые нужны приложению непосредственно во время его работы.

devDependencies

Это пакеты, которые используются преимущественно во время разработки, тестирования или сборки проекта. 

{
  "dependencies": {
    "98.css": "^0.1.20"
  },
  "devDependencies": {
    "eslint": "^9.0.0"
  }
}
Как создать package.json?

Создать файл можно автоматически с помощью команды: 

npm init

Если нужно сразу создать файл с настройками по умолчанию, используется: 

npm init -y

Именно команду npm init -y мы использовали при создании этого учебного проекта.
