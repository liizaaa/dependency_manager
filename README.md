# Dependency Manager

## Системы управления зависимостями (NPM, Composer)

Учебный веб-проект, посвящённый системам управления зависимостями NPM и Composer.

Проект содержит теоретическую информацию, сравнение NPM и Composer, инструкции по установке и практические примеры работы с зависимостями.

## О проекте

В проекте рассмотрены:

- NPM и его основные возможности;
- Composer и его основные возможности;
- файлы `package.json` и `composer.json`;
- установка, обновление и удаление зависимостей;
- файлы блокировки зависимостей;
- структура проектов;
- практические примеры команд;
- сравнение NPM и Composer;
- ответы на часто задаваемые вопросы.
