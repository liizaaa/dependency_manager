## Описание проекта

Учебный веб-проект посвящён системам управления зависимостями NPM и Composer.

В проекте рассмотрены основные возможности NPM и Composer, установка и управление зависимостями, файлы `package.json` и `composer.json`, файлы блокировки зависимостей, основные команды и различия между двумя системами.

Проект состоит из нескольких связанных HTML-страниц и содержит адаптивную навигацию, таблицы, формы, списки, практические примеры и обучающее видео.

Для оформления интерфейса используется CSS-фреймворк 98.css, имитирующий визуальный стиль Windows 98.
