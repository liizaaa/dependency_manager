Практический пример

Рассмотрим простой пример создания проекта с использованием NPM.

Предположим, что разработчик создаёт новый веб-проект и хочет использовать стороннюю библиотеку. Для управления этой библиотекой можно использовать NPM.

Шаг 1. Создание папки

Сначала создаём новую папку проекта: 

mkdir my-project

После этого переходим в созданную папку: 

cd my-project
Шаг 2. Инициализация NPM

Теперь создаём файл package.json: 

npm init -y

После выполнения команды NPM создаст конфигурационный файл проекта.

Шаг 3. Установка зависимости

Теперь установим библиотеку 98.css: 

npm install 98.css

После установки в проекте появится каталог node_modules.

Информация о библиотеке также будет записана в файл package.json.

Шаг 4. Проверка зависимости

Проверить установленные пакеты можно командой: 

npm list

В результате NPM покажет дерево установленных зависимостей проекта.

Шаг 5. Работа с package.json

После выполнения команд структура проекта будет примерно такой: 

my-project/
│
├── node_modules/
│
├── package.json
│
└── package-lock.json

Каталог node_modules содержит установленные пакеты.

package.json содержит информацию о зависимостях и настройках проекта.

package-lock.json фиксирует конкретные версии установленных зависимостей и их дерево.

Удаление зависимости

Если библиотека больше не нужна, её можно удалить: 

npm uninstall 98.css

NPM удалит пакет из проекта и обновит информацию о зависимостях.

Результат

Таким образом, NPM позволяет управлять зависимостями проекта практически на всех этапах разработки.

  1. Создать проект.
  2. Создать package.json.
  3. Установить необходимые пакеты.
  4. Проверить зависимости.
  5. Обновить или удалить пакеты.
