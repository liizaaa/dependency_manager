Установка NPM

NPM устанавливается вместе с Node.js. Поэтому для начала работы необходимо установить Node.js на компьютер.

После установки можно проверить наличие Node.js и NPM с помощью команд: 

node --version
npm --version

Если команды возвращают номера версий, установка выполнена успешно.

Создание NPM-проекта

Сначала необходимо создать папку проекта и перейти в неё через терминал: 

mkdir my-project
cd my-project

Затем создаётся файл package.json: 

npm init -y

После выполнения команды в папке появится файл package.json.

Установка пакета

Чтобы установить пакет, используется команда: 

npm install имя-пакета

Например, в нашем учебном проекте мы установили библиотеку 98.css: 

npm install 98.css

После установки NPM добавляет пакет в package.json и создаёт или обновляет package-lock.json.

Основные команды NPM
Часто используемые команды NPM
Команда Назначение
npm init Создание package.json
npm install Установка зависимостей
npm install package Установка определённого пакета
npm uninstall package Удаление пакета
npm update Обновление зависимостей
npm list Просмотр установленных пакетов
Установка Composer

Composer — менеджер зависимостей для PHP.

После установки Composer его работу можно проверить командой: 

composer --version

Команда должна вывести установленную версию Composer.

Создание проекта Composer

Для создания файла composer.json используется: 

composer init

После настройки проекта можно установить необходимые зависимости: 

composer install

Установленные пакеты будут помещены в каталог vendor.

Основные команды Composer
Часто используемые команды Composer
Команда Назначение
composer init Создание composer.json
composer install Установка зависимостей
composer require package Добавление пакета
composer update Обновление зависимостей
composer remove package Удаление пакета
Что выбрать?

Выбор менеджера зависимостей зависит от используемой технологии.

  • Для JavaScript и Node.js обычно используется NPM.
  • Для PHP-проектов используется Composer.

Оба инструмента решают похожую задачу: помогают устанавливать, обновлять и удалять зависимости проекта.
