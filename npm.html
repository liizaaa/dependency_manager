Dependency Manager — NPM
Что такое NPM?

NPM

NPM (Node Package Manager) - система управления пакетами для JavaScript и среды выполнения Node.js.

С помощью NPM разработчики могут устанавливать, обновлять и удалять сторонние библиотеки, необходимые для работы проекта.

NPM также позволяет описывать зависимости проекта в специальном файле package.json.

Основные возможности
  • Установка пакетов
  • Управление версиями
  • Обновление зависимостей
  • Удаление пакетов
  • Работа с package.json
  • Управление dev-зависимостями
Основные команды

Инициализация проекта:

npm init

Установка зависимости:

npm install 98.css

Удаление зависимости:

npm uninstall 98.css

Обновление пакетов:

npm update

Просмотр установленных пакетов:

npm list
Файл package.json

Файл package.json является одним из основных файлов проекта Node.js.

В нём хранится информация о проекте, его версии, командах и используемых зависимостях. 

{
  "name": "dependency-manager",
  "version": "1.0.0",
  "dependencies": {
    "98.css": "^0.1.21"
  }
}
